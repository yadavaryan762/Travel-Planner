# Travel Planner

## About the Project

Travel Planner is a simple desktop application developed using React and Electron. It helps users organize their trips by keeping track of destinations, travel dates, and budgets.

This project was created as a beginner-friendly desktop application project.

## Features

- Dashboard with trip summary cards
- Add new trips
- View all planned trips
- Edit existing trip details
- Delete trips
- Save trip information using localStorage
- Basic form validation
- Settings page with application information

## Technologies Used

- React
- JavaScript
- Electron
- HTML
- CSS
- Vite
- Browser localStorage

## Installation

Make sure Node.js and npm are installed on your computer.

1. Clone this repository.
2. Open the project folder in your terminal.
3. Install the project dependencies:

   ```bash
   npm install
   ```

4. Start the application using the appropriate development command defined in `package.json`.

## How to Use

1. Open the Travel Planner application.
2. Use the Dashboard to add a trip.
3. Enter the destination, start date, end date, and budget.
4. Open My Trips to view, edit, or delete trips.
5. Visit Settings to view application information.

## Data Storage

Trip information is saved locally using browser localStorage. The application does not require a separate database.

## Project Purpose

The purpose of this project is to learn the basics of React components, state management, event handling, local data storage, and building desktop applications with Electron.
